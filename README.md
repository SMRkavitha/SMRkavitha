# N. Kavitha portfolio

Static site (no build step). Deploy on Vercel:
1. Unzip, push the folder to a GitHub repo (or run `vercel` inside it).
2. In Vercel: Add New > Project > import the repo. Framework preset: Other. Leave build command and output directory empty.
3. Deploy.

To change the resume, replace `assets/Kavitha_Resume.pdf` (keep the same name).
